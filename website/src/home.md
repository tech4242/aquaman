aquaman is an open-source credential broker that runs on your machine. When Claude Code or Codex needs a key, it asks aquaman; you type the value into a system dialog, it is stored in the vault you already use (macOS Keychain, 1Password, Bitwarden, HashiCorp Vault, KeePassXC, Keeper, systemd-creds or an encrypted file), and it is set for the commands that need it. The value does not pass through the agent, the transcript or a `.env` file. No account. Your app still reads its keys from the environment.

It does the same job for agent hosts. OpenClaw and Hermes send model calls through a local proxy and hold a placeholder. Docker Sandboxes, NVIDIA OpenShell and Agent Substrate inject keys themselves and take them from your vault through aquaman.
