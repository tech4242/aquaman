# Agent Substrate protocol file

Vendored unchanged from [agent-substrate/substrate](https://github.com/agent-substrate/substrate) at
tag `v1.0.1` (commit `20778a6dbb01f13024642851bb592bf67c9fec05`),
`api/credprovider/v1/credprovider.proto`. Apache-2.0, see the header in the file.

`aquaman daemon` loads it at runtime to serve Substrate's credential provider API
(`substrate.credprovider.v1.CredentialProvider`). Update it together with the Substrate version
`scripts/e2e-substrate.sh` runs against.
