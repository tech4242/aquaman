# OpenShell protocol files

Vendored unchanged from [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) at tag `v0.1.2`
(commit `6648bd0c290efbc41ba131ee9831ee45cd431f94`), `proto/`. Apache-2.0, see the SPDX headers in
each file.

`aquaman daemon` loads them at runtime to serve the OpenShell external credential driver
(`credential_driver.proto`, extension protocol 1.0). Update them together with the CI lane's
OpenShell versions.
